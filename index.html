How these are built

Each example starts from a change in how work is done, defines the behaviour people now need, and lets them practise it in a short, realistic scenario with feedback. Where a standard or regulation applies, the feedback cites it and the learner leaves with a job aid.

Practical details

  • Single, self-contained web pages: no platform, licence or install
  • Work on desktop and mobile, with keyboard navigation
  • Content developed with AI, reviewed and structured by hand
  • Scenarios are illustrative and do not represent any organisation
