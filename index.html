How these are built

Each piece starts from a change in how work is done or how a subject is applied, defines what people now need to do, and lets them practise it with feedback. Where a standard or regulation applies, the feedback cites it.

Practical details

  • Single web pages: no platform, licence or install
  • Work on desktop and mobile, with keyboard navigation
  • Developed with AI, reviewed and structured by hand
  • Scenarios and businesses are fictional unless sourced
  • Designed for live classes and self-paced use: the facilitator runs discussion and group tasks; each piece also stands alone
